## 🔑 3. Android Permissions & Purpose

Orbis requests only the minimal set of Android system permissions strictly necessary to deliver its core multitasking functionality. Every permission is handled entirely on-device:

| Permission | Purpose & Scope |
| :--- | :--- |
| `SYSTEM_ALERT_WINDOW`<br>*(Display over other apps)* | Required to render the floating edge handle, sidebar dock, and resizable floating window above other applications. **Orbis does not read, capture, or record the contents of underlying screens.** |
| `QUERY_ALL_PACKAGES` | Allows Orbis to list installed applications inside the local app drawer so you can pin and launch your favorite apps into floating windows. **Installed package names are processed strictly in-memory and are never transmitted, logged, or uploaded to any server.** |
| `INTERNET` | Used exclusively for two explicit purposes:<br>1. Fetching read-only update metadata from GitHub (`version.json`) and downloading official APK updates when requested.<br>2. Loading websites directly requested by the user inside the built-in floating browser. |
| `POST_NOTIFICATIONS` | Android 13+ requirement to display a persistent background service notification, ensuring the floating overlay dock is not killed by the Android system while in use. |
| `REQUEST_INSTALL_PACKAGES` | Allows the user to trigger the installation of official Orbis updates downloaded via the built-in OTA updater. |
| `RECEIVE_BOOT_COMPLETED` | Allows the floating dock handle to automatically restore itself after device reboot (if enabled by the user in settings). |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | Optional user-granted exemption to prevent aggressive OEM battery management from terminating the floating service. |

## 💾 4. Local Data Storage

All data generated by your use of Orbis is stored strictly within the app’s private sandbox on your local device:

1. **User Preferences**: Pinned apps, dock edge side (left/right), window dimensions, and virtualization mode are saved in Android `SharedPreferences`.
2. **Browsing History**: The built-in browser saves visited URLs in a device-local SQLite database (`orbis_browser_history.db`) for auto-completion and navigation convenience. This database is private to the application and is never synced or uploaded anywhere.
3. **Cookies & Web Sessions**: Handled directly by Android’s native WebKit (`WebView`) engine. When you log into web services (like WhatsApp Web, YouTube, or Google), session cookies remain locally on your device.
4. **Data Deletion**: You can permanently delete all stored data at any time by going to **Android Settings → Apps → Orbis → Clear Storage / Clear Data**, or by uninstalling the app.
